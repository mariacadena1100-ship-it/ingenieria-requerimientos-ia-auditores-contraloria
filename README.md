# Ingeniería de Requerimientos - Aplicativo de IA para Auditores de la Contraloría

## Descripción
Proyecto orientado al desarrollo de un aplicativo basado en inteligencia artificial para apoyar a los auditores de la Contraloría General de la Nación en el análisis de información, identificación de hallazgos y optimización de procesos de auditoría.

## Objetivo General
Diseñar, documentar y estructurar el ciclo de vida de desarrollo de software para la construcción de una solución tecnológica inteligente orientada al apoyo de auditorías gubernamentales.

## Duración del Proyecto
6 meses

## Herramientas y Tecnologías a Utilizar

### Gestión y Documentación
- GitHub → Control de versiones y repositorio del proyecto
- Jira o Azure DevOps → Gestión de requerimientos, tareas y seguimiento del proyecto
- Confluence o SharePoint → Gestión documental y colaboración
- Microsoft Word y PDF → Elaboración de documentación técnica y reportes

### Diseño y Modelado
- Draw.io / StarUML → Diagramas UML y modelado del sistema
- Figma → Diseño de interfaces y prototipos

### Desarrollo
- Python → Desarrollo del motor de inteligencia artificial
- React.js o Angular → Desarrollo de la interfaz web
- API REST → Integración entre módulos y sistemas externos

### Inteligencia Artificial
- Machine Learning → Detección de anomalías y análisis predictivo
- NLP (Procesamiento de Lenguaje Natural) → Interpretación y análisis de texto

### Base de Datos y Almacenamiento
- PostgreSQL o MySQL → Gestión de base de datos
- Almacenamiento S3 Compatible → Gestión de documentos y evidencias

### Seguridad e Integración
- OAuth 2.0 → Autenticación segura
- Active Directory / LDAP → Gestión de usuarios y roles
- TLS 1.3 y AES-256 → Protección y cifrado de la información

### Pruebas y Calidad
- Pruebas funcionales
- Pruebas de rendimiento
- Pruebas de seguridad
- Validación UAT (User Acceptance Testing)
